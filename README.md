# Estudos de Python
Repositório destinado aos estudos, exercícios e práticas desenvolvidos durante a disciplina Computational Thinking Using Python, da graduação em Análise e Desenvolvimento de Sistemas na FIAP.

## Sobre a disciplina 
A disciplina tem como foco o desenvolvimento do pensamento computacional e da lógica de programação utilizando Python, construindo uma base sólida para a resolução de problemas e para o aprendizado de outras linguagens de programação.

Ao longo dos estudos, são explorados conceitos fundamentais e avançados de programação, buscando desenvolver a capacidade de transformar problemas reais em soluções computacionais.
